In-game A/B of the ambient occlusion (docs/RENDERER_BACKENDS.md, "Ambient occlusion"). Copy ao_scene.lua as <exe folder>/fafengine/lua/test/dynlights_test.lua and ao_camera.lua as dynlights_camera.lua there, with a header defining AB_PAUSE_AT (game seconds to pause at, 0 never), AB_MODES (a Lua list of ren_AmbientOcclusion values to cycle while paused), AB_HOLD (seconds each), AB_ZOOM and AB_RESIZE (true runs SC_PrimaryAdapter / windowed changes). Launch a skirmish on adaptive_acid_lakes with /windowed 1600 900 and FAF_GAL_DUMP_DIR + FAF_GAL_DUMP_SECONDS=1 for frames, FAF_GPU_PROFILE=300 for the region AmbientOcclusion.
